## عن الموقع

موقع تفاعلي سينمائي يعرض جدول المحاضرات والتمارين والمعامل لقسم الهندسة المدنية — تخصص الهندسة الإنشائية، المجموعة 1 سيكشن 1.

الموقع مصمم بتجربة مستخدم مميزة: شاشة مظلمة في البداية، ويسحب المستخدم الحبل ليضيء المصباح ويكشف الجدول.

---

## المميزات

- **تجربة تفاعلية**: سحب الحبل لتشغيل الإضاءة وكشف الجدول
- **تصميم سينمائي**: خلفية داكنة، إضاءة دافئة، جزيئات غبار، وتأثيرات بصرية
- **جدول منظم حسب الأيام**: السبت → الخميس
- **بطاقات المواد**: اسم المادة، الوقت، النوع (محاضرة / تمرين / معمل)، القاعة
- **متجاوب**: يعمل على الموبايل والكمبيوتر
- **أصوات خفيفة** عند التفاعل (اختياري)
- **دعم Reduced Motion** لمستخدمي تفضيل تقليل الحركة
